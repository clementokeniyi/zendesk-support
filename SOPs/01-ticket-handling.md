# SOP: Ticket Handling Process
**CJays Solutions Support Operations**

## Purpose
Ensure every customer ticket is handled consistently, professionally, and within SLA targets.

## Scope
All support agents handling tickets in Zendesk Support.

## Process

### Step 1 — Ticket Receipt (0–5 min)
- All incoming tickets auto-receive an acknowledgement reply via trigger
- Agent reviews ticket: read full description, check Issue Category field, check customer history

### Step 2 — Categorization & Assignment (5–10 min)
- Confirm the Issue Category is correctly set (Billing, Technical, Access, Inquiry, Feature)
- Routing trigger auto-assigns to correct group (Billing Support / Technical Support / General Support)
- If mis-routed, manually reassign to correct group

### Step 3 — First Response (within SLA)
- Normal priority: first reply within 8 business hours
- High priority: first reply within 4 business hours
- Use the "Acknowledge Receipt" macro as starting point, then personalize
- Never send a generic reply without reading the ticket first

### Step 4 — Resolution
- Investigate the issue, apply fix or provide answer
- Use "Resolve – Issue Fixed" macro when closing
- Add internal note summarizing what was done (for future reference)
- Set ticket status to Solved

### Step 5 — Follow-Up
- If no customer reply after 48 hours, automation sends follow-up and closes ticket
- Check CSAT score once received — flag any score below 3 for review
