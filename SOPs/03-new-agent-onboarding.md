# SOP: New Agent Onboarding
**CJays Solutions Support Operations**

## Purpose
Get new support agents productive in Zendesk within their first week.

## Day 1 — Access & Orientation
- [ ] Admin creates agent profile in Zendesk (Settings > People)
- [ ] Agent assigned to correct group (Billing / Technical / General)
- [ ] Agent given read-only access for first day to observe ticket flow
- [ ] Admin walks agent through: Views, Macros, Ticket fields, SLA policy

## Day 2 — Shadowing
- [ ] New agent shadows senior agent handling 5–10 tickets
- [ ] Review the 3 Help Center articles to understand common issues
- [ ] Agent reads all 4 SOPs in this folder

## Day 3–4 — Supervised Handling
- [ ] Agent handles tickets independently but senior agent reviews before sending
- [ ] Focus on correct Issue Category tagging and group assignment
- [ ] Practice using all 3 macros (Acknowledge, Follow-Up, Resolve)

## Day 5 — Independent
- [ ] Agent handles tickets independently
- [ ] Admin reviews first 10 tickets for quality
- [ ] Agent added to CSAT monitoring

## Key Things to Know
- Always check Issue Category field — routing depends on it
- SLA timers start the moment a ticket is created
- Use internal notes to document your thinking — don't just send replies
- When in doubt, escalate (see SOP-02)
